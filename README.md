
Client Site Analytics Dashboard (SQL + Power BI)
📌 Project Overview

This project was completed as the Week 4 Final Project during the LogicStack Data Analysis Internship (July 2026). The objective was to analyze user behavior, evaluate the customer conversion funnel, identify drop-off points, and build an interactive Power BI dashboard to support business decision-making.

The project combines SQL for data analysis and Power BI for data visualization to uncover actionable insights from website user activity.

🎯 Objectives
Analyze user behavior across different funnel stages.
Identify where users leave the conversion funnel.
Evaluate revenue performance across channels, regions, and devices.
Build an interactive dashboard for business stakeholders.
Generate insights and recommendations based on the analysis.

🔍 Key Insights
The largest drop-off occurs between Add to Cart and Checkout.
Google Ads generated the highest revenue among all marketing channels.
The South region contributed the highest revenue.
Desktop users showed strong engagement across the customer journey.
Total revenue exceeded 277K, generated from approximately 10K users.
💡 Business Recommendations
Simplify the checkout process to reduce cart abandonment.
Invest more in Google Ads as the highest-performing acquisition channel.
Focus marketing efforts on high-performing regions to maximize revenue.
