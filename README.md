# 📊 Client Site Analytics Dashboard

A complete Business Intelligence project developed using **SQL** and **Power BI** as part of the **Week 4 Final Project** during the **LogicStack Data Analysis Internship (July 2026)**.

The project focuses on analyzing customer behavior, understanding the conversion funnel, identifying user drop-off points, and generating actionable business insights through an interactive Power BI dashboard.

---

# 📌 Project Objectives

- Analyze website user behavior using SQL.
- Understand customer journey through the conversion funnel.
- Identify where users abandon the purchasing process.
- Analyze revenue across channels, devices, and regions.
- Build an interactive Power BI dashboard.
- Generate business insights and recommendations.

---

# 🔍 Key Insights

- Most users begin by browsing products, but a significant drop-off occurs before checkout.
- Google Ads generated the highest revenue among all acquisition channels.
- The South region contributed the highest revenue.
- Desktop users showed strong engagement throughout the customer journey.
- Customer behavior analysis highlights opportunities to improve conversion rates.

---

# 💡 Business Recommendations

- Optimize the checkout process to reduce cart abandonment.
- Invest more in high-performing marketing channels such as Google Ads.
- Launch targeted campaigns for high-revenue regions.
- Improve product pages to encourage users to add items to their cart.
- Continuously monitor funnel performance using interactive dashboards.
